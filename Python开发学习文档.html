00转型总纲：从其它语言到 Python

转型的第一步不是背语法，而是建立差异意识与 Pythonic 写法习惯。

解释型 + 动态强类型 + 胶水语言：迭代快，CPU 极致性能是弱项

  • 解释型逐行执行：启动快、迭代快
  • 动态类型需类型注解 + mypy 补强
  • 强类型：`"1" + 1` 直接报错，与 JS 弱类型不同
  • 一切皆对象：支持高阶函数、装饰器、元编程
  • 缩进是语法的一部分：统一 4 空格，禁止混用 tab

02基础语法与数据类型

变量是"名字到对象的引用"，六大类型的可变性决定一切行为差异。

变量是名字到对象的引用，不是存值的盒子

  • 重新赋值让名字指向新对象
  • -5~256 小整数池是 CPython 实现细节，不是语言规范
  • id() 相同不能单独证明缓存机制（可能受常量折叠影响）
展开代码与审校说明 
a = 10
b = 10
print(id(a), id(b))  # CPython 小整数缓存可能使地址一致，但这是实现细节
a = 20
print(id(a))         # 重新赋值指向新对象

审校说明：变量是"名字到对象的引用"，不是"存值的盒子"；小整数池行为不能作为跨实现依赖。

list/dict/set 可变，int/str/tuple 不可变——选型先看可变性与有序性

类型可变有序典型用途
int/float/bool不可变—数值
str不可变是文本
tuple不可变是固定记录
list可变是序列
dict可变3.7+ 有序键值
set可变无序去重/集合运算

默认参数在定义时求值一次，可变默认参数被所有调用共享

  • bad(1) 返回 [1]，bad(2) 返回 [1, 2]——意外共享
  • 正确做法：None 哨兵，函数体内新建
展开 bad vs good 代码 
# 错误：默认列表在函数定义时创建一次，被所有调用共享
def bad(item, bucket=[]):
    bucket.append(item)
    return bucket
print(bad(1))  # [1]
print(bad(2))  # [1, 2] ← 意外共享

# 正确：None 哨兵
def good(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

int("1.5") 报错、bool("") 为 False——动态强类型要求显式转换

  • str(123)、int("123")、list((1,2,3))、dict(name="李四")
  • int("1.5") 报错；float("1.5") 可用
  • bool("") 为 False；bool("0") 为 True
展开转换代码

str_num = int("123")
lst = list((1, 2, 3))
dic = dict(name="李四")

来自 JS/Java："1"+1 是 TypeError，HashMap 对应 dict，没有 char

  • JS 弱类型拼接在 Python 直接 TypeError，需显式转换
  • Java ArrayList → list、HashMap → dict、HashSet → set
  • str 不可变，但切片/拼接更灵活；单字符也是 str

04函数编程

参数四件套、LEGB 作用域与"传对象引用"语义是函数层的三大核心点。

位置/默认/*args/**kwargs 四类参数覆盖全部签名需求

  • 默认值在定义时求值
  • *args 收元组；**kwargs 收字典
展开代码 
def calc_sum(a: int, b: int) -> int:
    """两数求和。"""
    return a + b

def user_info(name: str, age: int = 18) -> None:
    print(f"姓名：{name}，年龄：{age}")

def args_demo(*args: int) -> None:
    print(args)          # 元组

def kwargs_demo(**kwargs: str) -> None:
    print(kwargs)        # 字典

user_info("张三")
args_demo(1, 2, 3)
kwargs_demo(skill="Python", level="精通")

LEGB 查找顺序：Local → Enclosing → Global → Built-in；少用 global

  • 优先用参数/返回值传递状态
  • global 修改模块级变量需显式声明
展开代码 
num = 100

def change_num() -> None:
    global num
    num = 200

change_num()
print(num)  # 200

传对象引用：不可变像值传递，可变的修改影响外部

  • 不可变对象（int/str/tuple）表现像值传递
  • 可变对象（list/dict/set）在函数内修改会影响调用方
  • Java 也是值传递（引用值），但 Python 没有 final、没有方法重载
  • 默认参数定义时求值 → 可变默认参数是经典坑

map/filter 返回迭代器，reduce 需从 functools 导入

  • lambda 用于 key 与回调：lst.sort(key=lambda x: x[1])
  • map/filter 是惰性迭代器，需 list() 或直接迭代
  • reduce 位于 functools，不可直接调用
展开代码与审校说明 
from functools import reduce

add = lambda a, b: a + b
lst = [(1, 3), (2, 1), (3, 2)]
lst.sort(key=lambda x: x[1])
nums = [1, 2, 3, 4]
new_nums = list(map(lambda x: x * 2, nums))     # map 返回迭代器
filtered = list(filter(lambda x: x > 2, nums))  # filter 返回迭代器
total = reduce(lambda a, b: a + b, nums, 0)     # 需导入 reduce

审校说明：Python 3 中 map/filter 返回迭代器，不是列表；reduce 必须显式导入。

  2. 用 reduce 求列表乘积。
  3. 解释 def f(x, acc=[]) 的问题并修复。

参考答案要点：return func(func(x))；reduce(lambda a,b:a*b, nums, 1)；用 None 哨兵。

05面向对象编程（P1 扩展）

封装靠约定 + property；接口用 Protocol/ABC；企业实践优先组合优于继承。

类属性共享、实例属性独有，__init__ 完成初始化

展开代码 
class User:
    species = "human"  # 类属性

    def __init__(self, name: str, age: int) -> None:
        self.name = name
        self.age = age

    def show_info(self) -> str:
        return f"用户{self.name}，年龄{self.age}"

封装靠约定（_ / __）+ property，不是强访问控制

  • 单下划线 = "内部使用"约定
  • __pwd 名称改写为 _User__pwd，仍可访问
  • property + setter 做受控读写与校验
展开代码与审校说明 
class Account:
    def __init__(self, owner: str, balance: float = 0.0) -> None:
        self.owner = owner
        self._balance = balance  # 约定：单下划线"内部使用"

    @property
    def balance(self) -> float:
        return self._balance

    @balance.setter
    def balance(self, value: float) -> None:
        if value < 0:
            raise ValueError("余额不能为负")
        self._balance = value

acc = Account("张三", 100)
acc.balance = 200
print(acc.balance)

审校说明：名称改写不等于私有；Python 靠约定 + property 做封装，不是强访问控制。

super().__init__ 先完成父类初始化再扩展子类状态

展开代码 
class Person:
    def __init__(self, name: str) -> None:
        self.name = name

class Student(Person):
    def __init__(self, name: str, stu_id: str) -> None:
        super().__init__(name)
        self.stu_id = stu_id

    def show(self) -> str:
        return f"学生{self.name}，学号{self.stu_id}"

Java interface 对应 Protocol（结构化）/ABC（名义）；日常优先鸭子类型

  • Protocol 静态检查按结构匹配，无需显式继承
  • 鸭子类型运行时按能力匹配
  • notify(n: Notifier) 接受任何有 send 方法的对象
展开代码 
from typing import Protocol

class Notifier(Protocol):
    def send(self, msg: str) -> None: ...

class EmailNotifier:
    def send(self, msg: str) -> None:
        print(f"Email: {msg}")

class SmsNotifier:
    def send(self, msg: str) -> None:
        print(f"SMS: {msg}")

def notify(n: Notifier, msg: str) -> None:
    n.send(msg)  # 鸭子类型 + 静态协议

notify(EmailNotifier(), "hello")
notify(SmsNotifier(), "hello")

  • 组合：Car 内嵌 Engine，不继承
  • 实例方法 / @classmethod / @staticmethod 三分
  • 支持多继承与 MRO，但企业更推荐组合

# 迭代器协议
class Countdown:
    def __init__(self, start: int) -> None:
        self.current = start

    def __iter__(self):
        return self

    def __next__(self) -> int:
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

装饰器是函数包装，必须 functools.wraps 保留元信息

  • 带参装饰器是"装饰器工厂"（两层嵌套）

展开 timer 与 retry 代码 
import functools
import time

def timer(func):
    @functools.wraps(func)  # 保留原函数元信息
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            print(f"{func.__name__} 耗时 {time.perf_counter() - start:.4f}s")
    return wrapper

def retry(times: int = 3, exceptions: tuple[type[Exception], ...] = (Exception,)):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_exc = None
            for _ in range(times):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_exc = e
            raise last_exc
        return wrapper
    return decorator

@timer
def test() -> None:
    time.sleep(0.1)

@retry(times=3, exceptions=(ValueError,))
def flaky() -> None:
    raise ValueError("boom")

from .db import get_conn
from .schemas import UserCreate, UserOut

class UserRepo:
    def create(self, data: UserCreate) -> UserOut:
        with get_conn() as conn:
            cur = conn.execute(
                "INSERT INTO users(name, age) VALUES (?, ?)",
                (data.name, data.age),
            )
            conn.commit()
            return UserOut(id=cur.lastrowid, name=data.name, age=data.age)

    def list(self) -> list[UserOut]:
        with get_conn() as conn:
            rows = conn.execute("SELECT id, name, age FROM users").fetchall()
            return [UserOut(id=r[0], name=r[1], age=r[2]) for r in rows]

    def get(self, uid: int) -> UserOut | None:
        with get_conn() as conn:
            row = conn.execute(
                "SELECT id, name, age FROM users WHERE id = ?", (uid,)
            ).fetchone()
            return UserOut(id=row[0], name=row[1], age=row[2]) if row else None

    def list_users(self) -> list[UserOut]:
        return self.repo.list()

    def get_user(self, uid: int) -> UserOut | None:
        return self.repo.get(uid)

src/user_service/api.py

from fastapi import APIRouter, Depends, HTTPException, status

from .repositories import UserRepo
from .schemas import UserCreate, UserOut
from .services import UserService

router = APIRouter(prefix="/users", tags=["users"])

def get_service() -> UserService:
    return UserService(UserRepo())

@router.post("", response_model=UserOut, status_code=status.HTTP_201_CREATED)
def create_user(data: UserCreate, svc: UserService = Depends(get_service)) -> UserOut:
    return svc.create_user(data)

@router.get("", response_model=list[UserOut])
def list_users(svc: UserService = Depends(get_service)) -> list[UserOut]:
    return svc.list_users()

@router.get("/{uid}", response_model=UserOut)
def get_user(uid: int, svc: UserService = Depends(get_service)) -> UserOut:
    user = svc.get_user(uid)
    if user is None:
        raise HTTPException(status_code=404, detail="user not found")
    return user
