如何添加 / 修改子页面点击展开
  1. 将新的笔记 HTML 文件放进本文件夹（PubNote/），文件名保持唯一。
  2. 打开 index.html，在底部脚本的 PAGES 数组中复制一行并修改字段。
  3. 保存并刷新本页，卡片、分类筛选、搜索会自动生效，无需改动其他代码。
// PAGES 配置模板 —— 新增一篇文章就复制这一段
{
  file:     "文件名.html",        // 必须与文件夹中的实际文件名一致
  href:     "",                   // 可选：指向子目录/其他页面（如 "ai/index.html"），优先于 file
  title:    "文档标题",
  desc:     "一句话摘要，最多两行",
  cat:      "分类名",            // 新分类会自动生成筛选标签
  tags:     ["标签一", "标签二"],
  date:     "2026-10-14",        // 格式 YYYY-MM-DD
  size:     "180 KB",
  featured: false,               // true = 首页大卡片，至多 1 篇
  badge:    ""                   // 可选角标，如 "持续更新中"
},
PubNote 本地知识库索引 · 数据由 index.html 内 PAGES 配置驱动
